# INCI Detective

Детектив косметических составов: разбор INCI по ролям, сравнение двух составов, словарь из 579 ингредиентов и режим «Миф или факт». Работает на русском, украинском и английском, без интернета после первого открытия.

## Как опубликовать на GitHub Pages
1. В этом репозитории откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**, нажмите **Save**.
3. Через 1–2 минуты приложение откроется по адресу `https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

## Как поставить на главный экран iPhone
Откройте адрес в **Safari** → кнопка «Поделиться» → **«На экран „Домой“»** → **«Добавить»**.

## Как обновлять
Загрузите новую версию `index.html` поверх старой (Add file → Upload files). При следующем запуске с интернетом приложение обновится.

Важно: справочные сведения не заменяют консультацию дерматолога. По одному списку INCI нельзя точно предсказать реакцию кожи.
